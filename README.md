## Hi, I'm Baucki👋
I am PhD student in Particle Physics, DIY-Enthusiast, Maker/Hacker

## ☢️⚛️ A bit about my work
Mostly interested in long-lived particles, exotic shower signatures, scientific computing and different applications of machine learning.

I am working on searches for long-lived particles decaying in the calorimeters of the ATLAS experiment at the Large Hadron Collider (LHC) at CERN using GNNs/GATs.

Apart from that, I'm also exploring 4D tracking at future colliders utilizing different machine learning concepts like metric learning, object condensation, GNNs and transformers.
